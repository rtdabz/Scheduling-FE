# Landing page screenshots

Real screenshots of TCCSched shown on the public landing page (`src/pages/landing`).
Each file is picked up by name; a missing file shows a "Screenshot coming soon" frame.

| File name (any of .webp/.png/.jpg) | Shown as |
|---|---|
| `dashboard-vpaa` | Hero preview and the Dashboards tab (VPAA) |
| `dashboard-dean` | Dashboards tab (Dean) |
| `dashboard-department` | Dashboards tab (Secretary, Program Head and Director share this view) |
| `schedule-management` | Schedule Management tab |
| `conflict-placement` | Conflict Detection tab, "Class placement" view |
| `conflict-detection` | Conflict Detection tab, "Instructor assignment" view |
| `recommendations` | Recommendations tab |
| `reports-department-schedule` | Reports tab, Department Schedule view |
| `reports-teaching-load` | Reports tab, Teaching Load view |
| `reports-room-utilization` | Reports tab, Room Utilization view |

Frames are 2:1. Capture the full app window at 1920px wide (about 1920x940, browser chrome
excluded), hide transient banners such as "The connection to the server is slow", and export at
1600px wide as WebP (quality ~85). Use realistic data and nothing you would not publish.
